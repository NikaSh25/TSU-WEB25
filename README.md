# TSU-WEB25

"A repository for the TSU Web Development course project. This project implements a design sourced from Figma, used strictly for educational purposes.
Website Project Requirements are:

1.  You should make at least 5 distinct pages.
2.  Use semantic HTML.
3.  Styling and JS should have their own seperate files.
4.  However, you are limited to one css file accross the whole website (all 5 pages share this css file)
5.  You must use CSS3: Background, gradient, box-shadow.
6.  You must use CSS3: Transition, Transform, Animations
7.  You must use Forms with its attributes.
8.  For colors use color wheel, HEX, RGBA and HSL
9.  Use at least one fragment of JS/Jquery in your project.
10. Design of the page must be pleasing.
11. You must use form with its methods using PHP.
12. You must use PHP string functions.
13. You must use PHP arrays.
14. You must use sessions and cookies.
15. You must use PHP file handling (write, read, delete, upload);
    "
